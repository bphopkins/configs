## 2. What the second chat learned

- **`compare.py` needs Pillow and numpy.** fedxps lacked Pillow until he
  installed the Fedora package on 2026-09-08; both machines have both now.
  Point the harness at the scratchpad with `FL_HARNESS_SCRATCH`; its default
  is under `/tmp`.
- **`run.sh` and `units.sh` share `build/`**: `run.sh` removes it first. Run
  them in sequence, never in parallel.
- **The comparison's direction.** `compare.py A B` reports B against A: a
  `+` line is present in B. The side-by-side images land in B's run
  directory with A on the left.
- **A census is part of a mode change.** The `\Lc` wrapper landed on
  2026-09-07 without `--recensus`, and the golden silently lacked a page for
  a day. After any change to a member's mode: recensus into a scratch file,
  diff it against `modes.tsv` (expect only the intended rows), land it, then
  `--update`.
- **Edit prose files with whitespace-insensitive anchors.** Every `.md` here
  is hand-wrapped; an exact multi-line anchor guessed from memory fails
  silently in `str.replace`. Assert the anchor count, and write nothing on
  failure.
- **bigfed runs the harness copy that is committed there.** `remote.sh` calls
  bigfed's own checkout of `run-suite.sh`, `compare.py` and `mode-census.py`;
  an uncommitted change to those scripts (the `\today` pin, on 2026-09-08)
  reaches bigfed only after his sync. The scratch `src`, by contrast, is
  always pushed from here.
- **`sync.sh` leaves build products in the scratch tree** (its excludes are
  not `--delete-excluded`), so the tree grows from 5 M to 22 M after a run
  and all of it is pushed. Harmless; `rm -rf` the scratch `src` if it
  matters.
- **Four documents in `opuscula/old/` load the stowed package with no frozen copy beside them** (three PHI 134 files and the PHI 212 paper). They are
  outside the harness and use none of the rename candidates; a rename would
  not touch them, but a change to a member they use would.

## 4. The grammar of the names: settled

Decided and landed on 2026-09-08 (section 1). The rule, in the map's
Conventions: a name is the letters as printed, CamelCase, digits spelled out;
an initial capital for a schema or a system, `ax` where the same letters also
name a system, lowercase for a frame condition, lowercase with `rule` for a
rule; decorations as suffixes. Left open by design: the `solo` rule differs
between the conditional operators and the metalanguage connectives — its own
ask, when its turn comes. Do not reopen the grammar; if a name reads wrong,
bring the cell.
